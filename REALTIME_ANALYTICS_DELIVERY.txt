                        QUICK START GUIDE
================================================================================

1. Verify Backend Files:
   $ cd backend
   $ python3 -m py_compile utils/realtime_trade_analytics.py
   $ python3 -m py_compile routes/realtime_analytics_routes.py
   (No output = success)

2. Start Backend:
   $ cd backend
   $ source venv/bin/activate
   $ python app.py
   (Should see: Running on http://0.0.0.0:4000)

3. Test API Endpoint:
   $ curl -H "Authorization: Bearer YOUR_TOKEN" \
      http://localhost:4000/api/analytics/realtime/live/user-metrics
   (Should return JSON with metrics)

4. Integrate into Frontend:
   - Follow INTEGRATION_STEPS.md for step-by-step guide
   - Add navbar link
   - Add page container
   - Update app.js
   - Test with trades

   - Open http://localhost:8000
   - Login
   - Click Analytics link
   - Execute test trades
   - View real-time metrics
