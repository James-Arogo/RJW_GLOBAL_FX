═══════════════════════════════════════════════════════════════════════════════
STEP 1: OPEN TWO TERMINALS
═══════════════════════════════════════════════════════════════════════════════

You need 2 terminal windows/tabs open:

□ TERMINAL 1: For backend (Flask server)
□ TERMINAL 2: For frontend (Web server)

Keep both open while using the app!

═══════════════════════════════════════════════════════════════════════════════
STEP 2: BACKEND SETUP (Terminal 1)
═══════════════════════════════════════════════════════════════════════════════

Copy & paste these commands in TERMINAL 1:

┌─ Command 1: Navigate to project
└─ cd ~/Desktop/RJW_GLOBAL_FX/

┌─ Command 2: Create Python virtual environment
└─ python3 -m venv venv

┌─ Command 3: Activate virtual environment
└─ source venv/bin/activate
   (On Windows: venv\Scripts\activate)
   
   ✅ You should see (venv) in your terminal prompt

┌─ Command 4: Navigate to backend
└─ cd backend

┌─ Command 5: Install dependencies (THIS MAY TAKE 2-3 MINUTES)
└─ pip install -r requirements.txt

   ✅ Wait for it to complete (should show "Successfully installed")

┌─ Command 6: Start the backend server
└─ python app.py

   ✅ WAIT FOR THIS MESSAGE:
       * Running on http://0.0.0.0:4000
       * Press CTRL+C to quit

   🟢 Backend is now running!
   
   ⚠️ DO NOT CLOSE THIS TERMINAL!

═══════════════════════════════════════════════════════════════════════════════
STEP 3: FRONTEND SETUP (Terminal 2 - NEW TERMINAL/TAB)
═══════════════════════════════════════════════════════════════════════════════

Open a NEW terminal tab/window and copy & paste:

┌─ Command 1: Navigate to web directory
└─ cd ~/Desktop/RJW_GLOBAL_FX/web

┌─ Command 2: Start the web server
└─ python3 -m http.server 8000

   ✅ YOU SHOULD SEE:
       Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...

   🟢 Frontend is now running!

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ PROBLEM: "ModuleNotFoundError: No module named 'flask'"
✅ SOLUTION: 
   - Make sure you ran: pip install -r requirements.txt
   - Try again: pip install flask flask-cors

❌ PROBLEM: "Port 4000 is already in use"
✅ SOLUTION:
   - Close other apps using port 4000
   - Or edit backend/app.py and change port from 4000 to 5000
   - Then access http://localhost:4000 becomes http://localhost:5000

❌ PROBLEM: "Port 8000 is already in use"
✅ SOLUTION:
   - Use different port: python3 -m http.server 8001
   - Then access http://localhost:8001

❌ PROBLEM: "Page not loading / blank page"
✅ SOLUTION:
   - Hard refresh browser: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)
   - Check if both servers are running (check terminal windows)

❌ PROBLEM: "Cannot login / Backend error"
✅ SOLUTION:
   - Check Terminal 1 shows "Running on http://0.0.0.0:4000"
   - If not, check for error messages
   - Restart backend: Ctrl+C then python app.py

❌ PROBLEM: "Prices not updating"
✅ SOLUTION:
   - Refresh the page
   - Click the "🔄 Refresh" button
   - Check that Terminal 1 backend is still running

❌ PROBLEM: "Cannot execute trade"
✅ SOLUTION:
   - Make sure you're logged in
   - Check your balance is high enough
   - Minimum amount is 1,000 KSH
   - Make sure stop loss < take profit
