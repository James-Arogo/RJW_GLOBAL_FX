📌 Overview

The RJW GLOBAL FX API provides real-time forex trading simulation with advanced analytics and risk management.

Property Value
Base URL http://localhost:4000/api
Authentication JWT Bearer Token
Content-Type application/json
Rate Limit 100 requests/minute

🔐 Authentication

Register User

POST/api/auth/register

Create a new user account

Request Body:

{ "username": "trader1", "email": "trader@example.com", "password": "SecurePass123!" }

Success Response (201):

{ "status": "success", "code": 201, "message": "Registration successful...", "data": null, "timestamp": "2024-01-28T..." }

cURL Example:

curl -X POST http://localhost:4000/api/auth/register \ -H "Content-Type: application/json" \ -d '{ "username": "trader1", "email": "trader@example.com", "password": "SecurePass123!" }'

Login

POST/api/auth/login

Authenticate and receive JWT token

Request Body:

{ "username": "trader1", "password": "SecurePass123!" }

Success Response (200):

{ "status": "success", "data": { "access_token": "eyJ0eXAiOiJKV1Q...", "refresh_token": "eyJ0eXAiOiJKV1Q...", "user": { "username": "trader1", "email": "trader@example.com", "balance": 1000.0 } } }

Authorization Header

Include JWT token in all authenticated requests:

Authorization: Bearer {access_token}

💱 Trading Endpoints

Get Live Prices

GET/api/trade/live_prices

Retrieve current prices for all currency pairs

Parameters:

None

Response Example:

{ "status": "success", "data": { "EUR/USD": 1.0985, "GBP/USD": 1.2512, "USD/JPY": 145.43, "XAU/USD": 1982.15 } }

Execute Trade

POST/api/trade/trade

REQUIRES AUTH - Execute a market order

Request Body:

{ "pair": "EUR/USD", "amount": 100.0 }

Supported Pairs:

EUR/USD, GBP/USD, USD/JPY, XAU/USD, USD/CHF, AUD/USD, NZD/USD, USD/CAD

📦 Response Format

All API responses follow this standardized format:

{
  "status": "success|error",
  "code": 200,
  "message": "Human-readable message",
  "data": {},
  "timestamp": "2024-01-28T...",
  "errors": []
}

⚠️ Common Error Codes

Error Code HTTP Status Description
BAD_REQUEST 400 Invalid request parameters
UNAUTHORIZED 401 Missing or invalid authentication
INSUFFICIENT_BALANCE 400 Insufficient funds for transaction
NOT_FOUND 404 Resource not found
VALIDATION_ERROR 422 Input validation failed
RATE_LIMIT_EXCEEDED 429 Too many requests
INTERNAL_ERROR 500 Server error
