TROUBLESHOOTING

Issue: "No module named fastapi"
Fix: pip install -r requirements.txt

Issue: "Address already in use :8000"
Fix: lsof -i :8000 && kill -9 <PID>

Issue: "Database connection error"
Fix: rm test.db && python main.py (recreates database)

Issue: "Import errors"
Fix: Ensure virtual environment is activated
